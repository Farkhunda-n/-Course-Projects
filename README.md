# -Course-Projects
This repository contains official projects and assignments completed for my IT, Networking, and Database courses.
It includes Cisco Packet Tracer labs, SQL/Access database projects, and other course-related work.



## Technologies Used
- Cisco Packet Tracer
- MySQL
- Microsoft Access
- SQL Queries
- Airtable
- Python (beginner)
- JavaScript (beginner)



## Installation
### For Packet Tracer Labs:
1. Install **Cisco Packet Tracer**
2. Download `.pkt` files from this repository
3. Open them in Packet Tracer

### For Database Projects:
1. Install **MySQL Workbench** or **Microsoft Access**
2. Download `.sql` or `.accdb` files
3. Open in the appropriate application
